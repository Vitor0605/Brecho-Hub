# ReVeste — Brechó Escolar

Uma vitrine de e-commerce para comprar e vender uniformes e materiais escolares usados.

## Recursos

- Catálogo com filtros por categoria e favoritos
- Tema claro e escuro
- Formulário para criar anúncios
- Área **Minhas vendas** para acompanhar anúncios criados no dispositivo
- Sem banco de dados e sem autenticação: os anúncios e preferências ficam no `localStorage` do navegador

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
